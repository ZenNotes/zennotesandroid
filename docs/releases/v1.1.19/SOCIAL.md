# Social copy: ZenNotes Android 1.1.19

## Short

ZenNotes for Android 1.1.19: Cloud sync skips work it already did,
images paste straight from your keyboard, sheets swipe away, and
wikilinks stop firing while you scroll. App core 2.47 rides along.

## Long

This update is about the editor staying out of your way. Cloud sync no
longer rereads notes and attachments it has already acknowledged, leaves
the views alone when nothing changed, and refreshes once for a batch of
incoming changes. Gboard and other keyboards can paste an image straight
into the note you are editing. Every sheet's handle drags and swipes
down to dismiss. Wikilinks open on a clean tap only, the selection
toolbar and the Cloud footer keep off the content beneath them, and the
launch splash shows the same square icon on every Android version.

App core 2.47 comes with it: a wikilink to a file in the vault opens the
file, switching Excalidraw drawings no longer overwrites the one you
opened, sync resumes when conflicted files already match, and local
tasks stay visible while Cloud conflicts wait. Comment replies made on
the phone now keep every thread and author intact.

No new permissions. Local and folder vaults still work without an
account. The sync work pairs with ZenNotes for iOS 1.9.9.
